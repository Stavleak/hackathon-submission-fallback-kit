# Contributing / Участие

EN: Open an issue with the observed problem, expected behavior and a small fictional example. For a fix, submit a pull request with the relevant language changes and verification. Keep event participants, private project files and credentials out of issues and examples. Run the repository's documented checks before submitting. A real event story requires permission and a source.

RU: Создайте issue с наблюдаемой проблемой, ожидаемым результатом и небольшим вымышленным примером. Для исправления откройте pull request с нужными языковыми версиями и проверкой. Не добавляйте данные участников, закрытые проекты и ключи в обсуждения и примеры. Перед отправкой выполните проверки из README. Реальная история события требует разрешения и источника.

Use English or Russian. Existing Kazakh resources remain welcome; do not remove an authored translation to simplify another language.

Можно писать на русском или английском. Казахские материалы также приветствуются. Не удаляйте готовый перевод ради упрощения другой версии.
